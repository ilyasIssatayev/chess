Score the decoded moves

After downloading the complete observation trace, run:

cargo run --offline -p chess-evaluation --bin observation-replay -- manifest.json observations.json > report.json

The Rust decoder runs without consulting reference moves. The report compares its committed history with annotations, counts incorrect or missing moves, reports gaps and compares completion intervals. Processing latency never replaces acquisition time.

This development workflow uses the base model and its own observation policy. It does not qualify side-camera accuracy or replace the audit of original live automatic decisions required for release.
